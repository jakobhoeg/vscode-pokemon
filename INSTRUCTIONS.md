I want to add funcitonality to this extension: https://github.com/jakobhoeg/vscode-pokemon to allow Pokemon to gain XP via user typing (coding) and eventually evolve when a certain amount of XP is reached. An (non-Pokemon) example of this functionality can be seen in this repo: https://github.com/blairjordan/codachi. However, the beauty of vscode-pokemon is it can fall back to a massive, already existing and well-defined system of gaining XP, leveling up, and upgrading/evolving the character. 

We should always follow whatever conventions already exist in the codebase as we are not hard-forking this but rather contributing.

Unit, integration, end-to-end testing, and manual testing should all be provided. 

The goal is to ultimately have this show up in a VSCode extension so make sure we follow whatever best practices exist for VSCode extensions.
